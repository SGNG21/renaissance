# Intégration dans la session Claude Code Renaissance

Ne pas `cp -R claude/.claude` par-dessus un dossier `.claude` existant sans comparer les noms, les triggers et les hooks. Ne jamais copier le `CLAUDE.md` de référence en remplacement du vrai fichier. Demander à Claude un patch court, commenté, appuyé sur ses instructions locales.

Ce pack **ne contient aucun hook exécutable**. Ses agents et skills sont des consignes textuelles facultatives, non des extensions installées. La compatibilité du frontmatter avec la version locale doit être contrôlée.

Conserver Superpowers/ECC/Agentic Council déjà actifs ; ne pas recopier les compétences équivalentes. Les agents de ce pack servent de scénarios de rôles pour tâches délégables, et non de « supers pouvoirs » supplémentaires.
