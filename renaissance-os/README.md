# Renaissance OS V7 — Pack maître Claude Code

Ce pack reproduit **la méthode de transmission du pack POLIVIA V7** sans prétendre recopier une application. Il concentre les décisions métier, les hypothèses techniques, les risques et les critères de recette. Il contient des références de conception à part, sans les installer ni les exécuter.

**Ne jamais substituer les fichiers de ce dossier au dépôt actif Renaissance sans rapprochement préalable des versions.** Les `contracts/` représentent une proposition de schéma inter-applications, non le schéma réel des bases existantes. Les `claude/.claude/agents` et skills sont des ressources de référence ; ils ne sont pas préinstallés.

Démarrage : lire `00_LIRE_EN_PREMIER.md` puis `MISSION_A_DONNER_A_CLAUDE.md`. Contrôle local du pack : `python3 scripts/validate_pack.py`. Voir `CHANGELOG_DECISIONS.md` pour résoudre les écarts entre le cahier initial et la décision intégrale actuelle.
